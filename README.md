# DNC Chits – public files

Static files used in WhatsApp template messages (document headers) sent from the
Google Form → WhatsApp Apps Script.

| File | Purpose |
|---|---|
| `DNC_Chits_Brochure.pdf` | Brochure attached to the `trichy_event` template |

To update a file, upload a new version with the **same file name** – the Apps Script
URL does not change.
